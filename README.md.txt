# Retail Customer Analytics

This repository demonstrates SQL, Python, and data quality analysis techniques commonly used in retail analytics.

# Retail Customer Analytics Portfolio

## Overview

This project demonstrates end-to-end retail analytics capabilities using SQL and Python, focusing on data quality validation, sales trend analysis, customer segmentation, and advanced window function analytics.

It reflects real-world analytics work similar to enterprise BI environments where data is used for reporting, KPI tracking, and decision-making.

---

## Business Objective

The goal of this project is to simulate how a data analyst would:
- Validate data accuracy before reporting
- Analyze sales trends over time
- Segment customers based on value and behavior
- Apply advanced SQL techniques for deeper insights

---

## Key Analytical Areas

### 1. Data Quality & Validation
- Duplicate detection
- Missing value checks
- Orphan record identification
- Source vs transformed data reconciliation

### 2. Sales Trend Analysis
- Monthly revenue trends
- Month-over-month growth analysis
- Running total calculations
- Performance comparison over time

### 3. Customer Segmentation
- High, medium, and low-value customer classification
- Purchase frequency analysis
- Repeat vs one-time customer identification

### 4. Advanced SQL (Window Functions)
- Ranking customers by spend
- Running totals per customer
- Lag-based comparisons (purchase behavior changes)
- Moving averages for trend smoothing
